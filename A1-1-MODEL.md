# A1-1 photo-reference model — visual draft

The ten photographs supplied on 2026-10-05 show the A1-1 EVA processing line
from the front, sides, and rear. The 2.5D model depicts its open cream frame,
front chrome and brown guide rollers, dark-green conveyor, large central drum
with a cream web, red control cabinet, overhead fan, and rear gantry. Original
photos and people are not embedded in the deployed application.

The model uses the existing A1-1 CAD footprint (initially 13.6 × 3.7 m), x/y,
rotation, and resized planar dimensions. It does not change the 2D drawing,
cloud records, or machine data. Vertical dimensions and the order of components
along the footprint are visual estimates from the photos, not survey data.
Feed/collection direction has not been confirmed, so the A1-1 close-up does not
show directional labels. The H1-1 model remains independent and unchanged.

Preview: open 2.5D Twin, select A1-1, then choose 設備特寫 (Thai:
ดูอุปกรณ์ระยะใกล้). Rotation and resizing in the 2D plan carry into the model.
